# Phase I Flight Test Plan

*(skeleton, to be completed before the airworthiness inspection)*

## Before first flight

- Weight and balance from actual scale readings, all three points
- CG verified at 30% MAC across the full pilot weight range
- Full-deflection control checks, both directions, eyes on the surfaces
- Spoileron aerodynamic close direction measured at 25 and 35 mph on taxi
- Wing pin engagement verified, all four per side, lanyards visible
- Static thrust measured
- Engine run to temperature, both ignition circuits checked independently
- Junco logging confirmed to SD

## Test area

To be assigned in the operating limitations. Requirements: long paved runway,
minimal traffic, no jet mix, and 40 hours of flyable airspace.

## Test sequence

1. High-speed taxi, nosewheel steering and brake authority
2. Runway hops, elevator authority in ground effect
3. First flight: pattern altitude, straight and level, trim, gentle turns
4. Stall series, progressive, at altitude, clean then with slats characterized
5. Spoileron roll rate and authority, measured against stick position via Junco
6. Climb performance, corrected for density altitude
7. Glide ratio, measured by timed descent
8. Takeoff and landing distances, measured
9. Envelope expansion to Vne in increments

## Data to publish

Every number in the README that is currently an estimate, replaced with a
measurement, with the Junco logs alongside it.
